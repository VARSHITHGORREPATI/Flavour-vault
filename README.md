# 🍲 Flavour Vault

A React recipe discovery application for browsing recipes, exploring categories, and viewing detailed recipe information.

## ✨ Features

- Browse recipes by category
- Recipe details pages
- Client-side routing with React Router
- JSON-backed local recipe data
- Responsive recipe browsing experience

## 🛠️ Tech Stack

- React 17
- React Router
- JavaScript, HTML, CSS/Sass
- JSON Server
- React Icons

## 🚀 Run Locally

```bash
git clone https://github.com/VARSHITHGORREPATI/Flavour-vault.git
cd Flavour-vault
npm install
```

Start the data server and frontend in separate terminals:

```bash
npm run server
npm start
```

The project uses JSON Server for local recipe data. Check `package.json` for the current configured port and scripts.
